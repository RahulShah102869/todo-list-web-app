# Modern To-Do List Web App

Welcome to my To-Do List Web App!

A modern, responsive, and interactive To-Do List application built using HTML, CSS, and JavaScript. It helps users manage daily tasks, track their progress, and stay organized through a clean, user-friendly interface with a glassmorphism-inspired design.

## 🌐 Live Demo

🔗 **Website:** [Try To-Do List](https://todo-list-webv1.netlify.app/)

## Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, animations, and responsive layouts
- **JavaScript** – Interactive task management
- **LocalStorage** – Stores tasks in the browser
- **Netlify** – Website hosting and deployment

## Features

- ➕ Add and manage daily tasks
- ✅ Mark tasks as completed
- 📊 Track task progress
- 💾 Save tasks using LocalStorage
- 📱 Responsive design for different screen sizes
- 🎨 Modern glassmorphism-inspired UI
- 🖱️ Interactive controls and user-friendly navigation

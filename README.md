# ✅ Modern To-Do List Web App

Welcome to my To-Do List project! 👋

A modern, responsive, and interactive To-Do List web application built using HTML, CSS, and JavaScript. It helps users manage daily tasks, track progress, and stay organized with a clean, glassmorphism-inspired user interface.

## 🌐 Live Demo

🔗 **Website:** [Try To-Do List](https://todo-list-webv1.netlify.app/)

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, animations, and responsive design
- **JavaScript** – Task management and interactive functionality
- **LocalStorage** – Saving tasks in the browser
- **Netlify** – Website hosting and deployment

## ✨ Features

- Add and manage daily tasks
- Mark tasks as completed
- Track task progress
- Save tasks using LocalStorage
- Responsive design for different screen sizes
- Modern glassmorphism-inspired UI
- Simple and user-friendly interface
